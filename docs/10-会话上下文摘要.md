## 3. 技术形态

- 后端：零依赖 Node（`node:http`、JSON 持久化、PBKDF2、HMAC-SHA256 Token、统一 `{code,message,data}`）。
- 前端：原生 ES Module + 手写组件/SVG 图表，无构建步骤；设计系统深蓝侧栏 + 浅色工作台，大屏暗色。
- OCR：`POST /api/ocr` 优先本地 RapidOCR（Python，`tools/ocr.py`），失败回退 Windows OCR（`tools/ocr.ps1`）；`server/ocr.mjs` 做坐标解析、关键词匹配与值归一化。
- 本地已安装 `rapidocr_onnxruntime 1.4.4`（DSH 自带 Python）。换环境运行 `tools\setup-ocr.cmd`，或 `python -m pip install rapidocr_onnxruntime`；未装时自动回退 Windows OCR，准确率较低。
- 迁移正式系统：替换 `public/js/core/api.js`，视图迁 Vue 3；OCR 可替换云端服务。

## 5. 核心功能与接口

### OCR

- `POST /api/ocr`（ADMIN/RM/PM）：body `{filename,mime,dataBase64}`；限 12MB；返回 `{engine,fields,warnings,rawText,matchedCount,durationMs,...}`。
- 实测用户 ERP 高清截图：RapidOCR 约 1.8 秒，匹配 21 个字段：项目名称、项目代号、承担部门、负责人、计划开始/完成时间、合同运行额、成本控制额、代号类型、结算状态、立项时间/序号、项目总工、安全员、工期、立项经费说明、预立项/重大立项/转化项目勾选等。
- 成本控制额（元）自动 ÷10000 转为批复经费（万元）。
- 前端「允许修改识别结果」默认开；关闭后禁用本次识别到的字段，打开恢复；未识别字段始终可填。
- OCR 识别临时文件不落库；识别成功后删除。
- 字段 OCR 关键词可在系统管理→项目字段编辑。

### ERP 字段（默认 32 个：23 ERP + 9 系统）

ERP 组：项目名称、项目简称、项目代号、承担部门、项目负责人、计划开始时间、计划完成时间、合同运行额（元）、成本控制额（元）、税款类别、代号类型、计划利润（元）、预立项、是否重大立项项目、结算状态、立项时间、立项序号、项目总工、项目安全员、是否转化项目、工期、立项经费说明、备注。

系统组：项目编号、项目级别、项目来源、经费来源、项目状态、整体进度、批复经费、ERP 采购申请编号、采购询比系统编号。默认隐藏项目编号/级别/来源/经费来源/采购/询比（可在字段配置启用）。

- 表单按 `group` 渲染“ERP 基本信息 / 系统信息”分组。
- 支持类型：text、textarea、number、date、select、checkbox、department、manager、status。
- 锁定字段：name、deptId、managerId、startDate、endDate、status、fundTotal。
- 字段值保存在 `project.customFields`；详情「项目信息→自定义信息」展示，布尔值显示是/否。

### 项目字段/内容/菜单配置

- `GET/PUT /api/project-fields`（PUT：ADMIN/RM）保存字段；字段含 `group`、`ocrKeywords`、`options`、`full`、`required`、`enabled` 等。
- 字段行可拖拽排序；下拉字段「选项」按钮可增删改和上下移动选项内容；保存配置后新建/编辑表单即时生效。
- `GET/PUT /api/menus`（PUT：仅 ADMIN）：14 个菜单启停；`/`、`/projects`、`/system` 锁定；停用后侧栏隐藏，直接访问显示“该菜单已停用”。
- 前端 `app.js` 用 `options.menus` 过滤导航与路由守卫。

### 其他已有功能

- 流程模板拖拽设计器：节点块移动/缩放、材料跨节点拖拽、节点排序、属性检查、生效预览、保存快照。
- 项目详情：材料拖拽上传、抽屉上传/附件预览下载删除、逾期补传、无需提交/重置、季度报表、经费台账、项目信息/自定义信息/日志。
- 看板、项目台账、季度执行、逾期提醒、七类分类台账、系统管理（用户/部门/字段/菜单/日志）、展示大屏。
- 权限：ADMIN 全功能；RM 全项目+模板+字段+日志（无账号/菜单管理）；PM 仅本人项目；VIEWER 只读。

## 7. 注意事项 / 已知限制

- **无 MySQL**；不要把文档里的 3307 当成当前原型数据库。
- 启动脚本必须保持 `start.cmd`/`stop.cmd` **ASCII + CRLF**；`start.ps1`、`stop.ps1`、`ocr.ps1` 保持 **UTF-8 BOM**；否则中文 Windows cmd/PowerShell 5.1 会解析失败。
- OCR 准确率依赖截图清晰度和版式；换 ERP 版式优先改字段的 OCR 关键词，必要时扩展 `server/ocr.mjs` 配对逻辑。
- Node 不在 PATH；只通过 `start.cmd` / `start.ps1` 启动。
- 原型安全/并发为演示级；Token 存 localStorage；单文件附件 20MB；OCR 12MB。
- `verify.mjs` 会改动数据并在结尾重置；不要在生产演示数据上直接跑。
- 正式系统设计仍为 Spring Boot + MySQL + Vue 3（`docs/02/03/04`），当前工作区无正式源码。
