## 5. 已知事项

1. 当前 Word 文档中的流程图以“见 Markdown 源文件”提示替代 Mermaid 图形，正式汇报前可用 Visio/ProcessOn 重绘。
2. 项目材料打包下载、邮件/企业微信提醒为后续扩展，不在本期范围。
3. 大屏访问码是内网共享密钥，不是强身份认证。
4. 测试覆盖以核心密码组件 + 手工接口/页面验证为主，未引入 Testcontainers 全链路自动化测试。
5. 生产环境不要执行 `db/schema.sql`，应使用增量迁移。
